# Trio Majestica Hotel Management System

A full-stack Hotel Management System developed using the MERN Stack. The system is designed to manage hotel rooms, reservations, guests, payments, housekeeping, staff, and hotel operations through a responsive web application.

## Project Overview

The Trio Majestica Hotel Management System provides a centralized platform for managing daily hotel operations. It supports different user roles and provides role-based access to hotel management features.
